An interactive 3D WebGL engineering portfolio built with **React (Vite) + Three.js (`@react-three/fiber`, `@react-three/drei`) + Tailwind CSS + Framer Motion**.

---

## ✨ Key Architectural Features
- **3D Animated Milky Way Spiral Galaxy Background:** 9,500-star logarithmic spiral galaxy + 1,200 cosmic nebula dust clouds with smooth cursor parallax.
- **29-Point Skill Matrix & 3D Orbital Constellation:** Toggle between the **Cybernetic Bento Matrix View** (5 engineering clusters) and an interactive **3D Orbital Node View**.
- **Ongoing Projects & R&D Lab:** Extensible blueprint architecture (`src/data/projectsData.js`) synchronized with [@Ajin120607](https://github.com/Ajin120607).
- **Verified AWS / Credly Badge Triad:** 3D holographic tokens with live verification links to Credly.
- **12 Verified Certificates & Specializations Vault:** Interactive category filtering + High-Resolution Fullscreen Lightbox Modal with Zoom & PDF verification.
- **Direct-to-Email Feedback & Contact Command Terminal:** Zero-config automated delivery + direct `mailto:` fallback to `mailtoajinsamuel@gmail.com`.
